## First publication on GitHub Pages

1. Open your repository:
   `HamedPourzolfaghar/HamedPourzolfaghar.github.io`
2. Choose **Add file → Upload files**.
3. Upload:
   - `index.html`
   - `style.css`
   - the entire `assets` folder / photo file
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select:
   - Branch: `main`
   - Folder: `/ (root)`
8. Save.
9. After a short wait, visit:
   `https://HamedPourzolfaghar.github.io`
